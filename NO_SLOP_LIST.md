# The no-slop list

These 20 design and writing patterns mark something as AI-generated. We don't use any of them, in any post, video, carousel, doc or page.

| # | Never | Do this instead |
|---|---|---|
| 1 | Tags and pills (rounded labels and chips) | Plain text, or a square highlight on the word itself |
| 2 | Excessive italics | Upright type. Headlines are one colour, with no single coloured or highlighted word |
| 3 | Instrument Serif | Our brand faces only: Bricolage Grotesque, Inter and Fraunces |
| 4 | Negative kerning (letters squeezed together) | Default letter spacing, 0 or more |
| 5 | Over-detailed UI | Show only the part that carries the point |
| 6 | Too many dividers | Use space to separate things, not lines |
| 7 | Lots of color shades and opacities | A few solid colors: background, text, one muted tone, brand green |
| 8 | Everything in a bordered container | Content sits on the page. Use a box only when the real thing is a box (a phone, a note) |
| 9 | Over-detailed diagrams | The fewest parts that make the point |
| 10 | Wordy, repetitive copy | Say it once, in the fewest words |
| 11 | Code breadcrumbs (file paths, `a / b / c` navigation) | Plain words |
| 12 | Section numbering (1.1, 1.2, 2.1) | Headlines that say what the section is |
| 13 | Eyebrows (small label text above a headline) | Let the headline stand alone |
| 14 | Dithering and pixel textures | Flat color or real photos |
| 15 | ASCII art and text graphics | Real images or clean shapes |
| 16 | Squircles (rounded squares) | Square corners, or true circles where the real thing is round |
| 17 | Too much monospace | Mono only for actual times on a clock, and sparingly |
| 18 | ALL CAPS subtitles and headings | Sentence case everywhere |
| 19 | Gradient backgrounds | Solid backgrounds |
| 20 | Periods at the end of titles and headlines | No period on a headline. Body sentences keep theirs |
